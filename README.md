# משחק זיכרון מדינות ודגלים

יישום ריאקט (TypeScript + Vite) של משחק זיכרון בו צריך להתאים בין שם מדינה לדגל שלה.

## הפעלה מקומית

1. התקינו את התלויות:

   ```bash
   npm install
   ```

2. הריצו את שרת הפיתוח:

   ```bash
   npm run dev
   ```

3. פתחו את הדפדפן בכתובת שמופיעה במסוף (ברירת מחדל: `http://localhost:5173`).

## תיאור חוויית המשחק

- לחיצה על הכפתור "התחל משחק חדש" מערבבת את הקלפים ומתחילה סבב חדש.
- בכל תור ניתן לבחור שני קלפים. אם הם תואמים (שם מדינה והדגל שלה) הקלפים יאירו וייעלמו.
- לאחר שהקלפים נעלמים הלוח מתעדכן כך שהקלפים הנותרים מתרכזים יחד.
- כאשר כל הזוגות נמצאו תופיע הודעת ניצחון עם אפשרות לשחק שוב.

## מבנה הפרויקט

- `src/components/MemoryGame.tsx` – לוגיקת המשחק והצגת הלוח.
- `src/styles/` – קבצי העיצוב (CSS).
- `flags/` – קבצי הדגלים שבהם נעשה שימוש במשחק.

## טכנולוגיות

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) לסביבת פיתוח מהירה ויעילה.
