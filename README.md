# משחק זיכרון מדינות ודגלים

יישום ריאקט (TypeScript + Vite) של משחק זיכרון בו צריך להתאים בין שם מדינה לדגל שלה, עם תמיכה במצב כהה ובמעקב אחרי זמן המשחק ומספר הניחושים.

## הפעלה מקומית

1. התקינו את התלויות:

   ```bash
   npm install
   ```

2. הריצו את שרת הפיתוח:

   ```bash
   npm run dev
   ```

3. פתחו את הדפדפן בכתובת שמופיעה במסוף (ברירת מחדל: `http://localhost:5173`).

## תיאור חוויית המשחק

- בפס העליון תמצאו בורר מצב תצוגה המאפשר לבחור בין מצב מערכת, מצב בהיר ומצב כהה. ברירת המחדל היא התאמה אוטומטית להגדרת המערכת.
- לצד הבורר מוצגים שעון שסופר את משך המשחק (שעות, דקות ושניות) ומונה של מספר הניחושים שבוצעו עד כה.
- לחיצה על הכפתור "התחל משחק חדש" מערבבת את הקלפים ומתחילה סבב חדש.
- בכל תור ניתן לבחור שני קלפים. אם הם תואמים (שם מדינה והדגל שלה) הקלפים יאירו וייעלמו.
- לאחר שהקלפים נעלמים הלוח מתעדכן כך שהקלפים הנותרים מתרכזים יחד.
- כאשר כל הזוגות נמצאו תופיע הודעת ניצחון עם אפשרות לשחק שוב, כולל פירוט הזמן שחלף ומספר הניחושים בסבב.

## פריסה

- כל מיזוג לענף `main` מפעיל בנייה ופריסה אוטומטית ב-Netlify.
- גרסת ההפקה של המשחק זמינה בכתובת: https://countrymemorygame.netlify.app/

## מבנה הפרויקט

- `src/components/MemoryGame.tsx` – לוגיקת המשחק והצגת הלוח.
- `src/styles/` – קבצי העיצוב (CSS).
- `flags/` – קבצי הדגלים שבהם נעשה שימוש במשחק.

## טכנולוגיות

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) לסביבת פיתוח מהירה ויעילה.
